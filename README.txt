WEBSITE EDUKASI NARKOBA — KELAS XI RPL

Cara menjalankan:
1. Ekstrak folder website_edukasi_narkoba_rpl11.zip.
2. Buka foldernya di Visual Studio Code.
3. Klik kanan index.html lalu pilih Open with Live Server (jika ekstensi Live Server tersedia).
   Alternatif: buka index.html langsung di browser.
4. Semua halaman terhubung lewat menu navigasi di bagian atas.

Struktur:
- index.html: Beranda
- pengertian.html: Pengertian narkoba
- jenis-narkoba.html: Jenis dan risiko
- dampak.html: Dampak penyalahgunaan
- pencegahan.html: Cara pencegahan
- bantuan.html: Bantuan dan rehabilitasi
- artikel.html: Artikel edukasi
- faq.html: Pertanyaan umum
- kontak.html: Form demo (belum terhubung database)
- style.css: Tampilan responsif
- assets/: ilustrasi SVG lokal yang dibuat untuk website

Cocok untuk proyek kelas XI RPL karena menggunakan HTML, CSS, struktur multipage,
navigasi antarhalaman, semantic tags, responsive layout, dan sedikit JavaScript
untuk demo formulir. Konten bersifat edukasi; untuk keadaan kesehatan nyata,
hubungi tenaga kesehatan atau layanan resmi.
